# ゴルーレッフ



## 作品概要

DirectX11で制作した、ゴルフとルーレットを組み合わせたゲームです。



## 技術スタック

- C、C++
- DirectX11
- XAudio2
- ImGui
- yaml-cpp
- Visual Studio 2022



## 課題解決

- 物理演算の実装
	- ゴルフボールの物理演算をAABBと衝突判定を用いて実装しました。
	- ゴルフボールの挙動を、よりリアルにするために重力を実装しました。



## 工夫した点

物理挙動の他にUIの演出も力を入れ、動きをつけています。
打数が少ないほど高いランクをとることが出来るようにすることで、プレイヤーに達成感を与えるようにしました。



## 得られた学び

今作はAABBで実装しましたが、OBBもあると知るきっかけになりました。
UIの演出も、動きをつけることでより魅力的になることを学びました。
物理挙動について深く勉強できた作品となりました。



## 操作方法

スペースキーでルーレットを止め、球を発射します。
最高ランクはSランクで、打数が少ないほど高いランクをとることが出来ます。
